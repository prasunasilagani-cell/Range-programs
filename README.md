#Range Programs in JavaScript

This task contains JavaScript programs that perform different number operations within specified ranges.

###Programs Covered

* Sum of prime numbers
* Average of perfect numbers
* Leap years
* Palindrome numbers
* Numbers with digit sum 10
* Pairs with target sum 30
* Numbers with exactly 3 factors
* Prime factors
* Armstrong numbers
* Number with maximum factors

###Concepts Used

* `for` loops
* `while` loops
* Nested loops
* Conditional statements
* Number and digit operations

Technology: JavaScript
